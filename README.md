# Taller 6 - GUI con Swing y Java2D

## Descripción

Aplicación de escritorio desarrollada en Java utilizando Swing y Java2D, que permite administrar un diario de restaurantes visitados y por visitar.

Cada restaurante tiene un nombre, una calificación de 1 a 5, un estado de visitado y una ubicación en un mapa.

## Funcionalidades

- Visualizar una lista de restaurantes.
- Consultar el nombre, la calificación y el estado de visitado.
- Agregar nuevos restaurantes.
- Seleccionar la ubicación de un restaurante haciendo clic sobre un mapa.
- Visualizar los restaurantes en un mapa mediante Java2D.
- Filtrar los restaurantes entre todos y visitados.

## Tecnologías utilizadas

- Java
- Swing
- Java2D
- Eclipse IDE

## Instrucciones de ejecución

1. Descargar o clonar este repositorio.
2. Abrir Eclipse IDE.
3. Seleccionar `File > Import > Existing Projects into Workspace`.
4. Seleccionar la carpeta `ProyectoEclipse`.
5. Importar el proyecto.
6. Buscar la clase `VentanaPrincipal` en el paquete `uniandes.dpoo.swing.interfaz.principal`.
7. Hacer clic derecho sobre la clase y seleccionar `Run As > Java Application`.

**Nota:** Si las imágenes no aparecen, configurar el `Working directory` en `Run Configurations > Arguments` para que apunte a la raíz del proyecto Eclipse, donde se encuentra la carpeta `imagenes`.
